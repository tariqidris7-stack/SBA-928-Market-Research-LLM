# SBA 928 - Enhancing Market Research with AI Prompt Engineering

## Project Overview

This project was developed for SBA 928 - Enhancing Market Research with AI Prompt Engineering.

The objective of the project is to demonstrate how a pretrained language model can be fine-tuned to generate more relevant, structured, and actionable market research responses.

The project includes a structured market research dataset, training and validation data, held-out evaluation data, model fine-tuning, training logs, saved model adapter files, base-model outputs, fine-tuned outputs, and model performance comparisons.

## Base Language Model

The base model used for this project is:

**Google FLAN-T5 Small**

Model identifier:

`google/flan-t5-small`

FLAN-T5 was selected because it is an instruction-tuned sequence-to-sequence language model that can be efficiently fine-tuned for structured prompt-response tasks.

## Fine-Tuning Method

The model was fine-tuned using:

- Hugging Face Transformers
- PEFT
- LoRA (Low-Rank Adaptation)
- PyTorch
- Google Colab GPU runtime

LoRA was used to train a smaller set of adapter parameters instead of retraining every parameter in the base model.

## Dataset

The dataset contains structured market research prompt-and-response examples covering areas including:

- Consumer behavior
- Market trends
- Competitor analysis
- Customer satisfaction
- Marketing strategy
- Demographic analysis
- Regional analysis
- Predictive market research

The complete dataset was divided into:

- Training data
- Validation data
- Held-out test data

The held-out test prompts were not used to train the model and were reserved for final evaluation.

## Training Configuration

The experiment used the following primary settings:

- Base model: `google/flan-t5-small`
- Fine-tuning method: LoRA / PEFT
- LoRA rank: 8
- LoRA alpha: 16
- LoRA dropout: 0.1
- Learning rate: 5e-4
- Training epochs: 10
- Training batch size: 4
- Validation batch size: 4
- Weight decay: 0.01
- Evaluation strategy: Every epoch
- Model selection metric: Validation loss

## Model Evaluation

The original base model and fine-tuned model were evaluated using the same held-out test prompts.

The repository contains the actual responses generated by both models.

A TF-IDF cosine similarity evaluation was also performed by comparing generated responses with the expected market research responses.

The resulting files are located in the `outputs` directory.
